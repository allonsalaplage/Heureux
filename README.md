# Heureux

Site collaboratif qui fédère des idées, projets, réalisations et procédés positifs pour collaborer à façonner un monde heureux.

## Site web

Ce dépôt contient une page web statique prête pour GitHub Pages.

- `index.html` : page d’accueil
- `style.css` : mise en forme
- `script.js` : JavaScript de base

## Publication avec GitHub Pages

Dans GitHub : **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
